# Support

## Questions and design discussion

Use GitHub Discussions for architecture, integrations, evaluation design, and adoption questions.
Include the deployment mode, version, task type, and expected authorization behavior.

## Bugs

Open a GitHub issue with:

- Secure Context Cache version or commit;
- local, Docker, Kubernetes, or AWS mode;
- minimal reproduction steps;
- expected and observed behavior; and
- sanitized logs or JSON with secrets and organization data removed.

## Security

Do not open a public issue for a vulnerability or possible context exposure. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md).

## Commercial or pilot inquiry

For a controlled evaluation or pilot, email `nagamuppidi1015@gmail.com`. Do not email credentials,
private repositories, source archives, or production logs.
