Lower input-token spend per accepted agent result.

Security by architecture

The model never owns the authority boundary.

Models explain and recommend. Deterministic services authenticate callers, evaluate policy, release context, and preserve evidence. The automated AWS stack is designed for controlled evaluation; the repository documents the hardening required before broad production use.

FAQ

Questions teams ask before a pilot.

For implementation details, use the repository's getting-started, security, deployment, and production-readiness guides.

How do Secure Context Cache, Agent Context Gateway, and SecureReviewAgent relate?+

Secure Context Cache is the research-backed framework. Agent Context Gateway is the deployable API and AWS control plane. SecureReviewAgent is the flagship Infrastructure-as-Code security application built on governed capsules.

Is this another RAG framework?+

No. Retrieval finds relevant content. Secure Context Cache adds an authorization boundary: who or what is asking, for which task and path, at what sensitivity, under which policy, with what evidence.

Does it replace a model gateway?+

No. It sits before the model gateway. ACG governs which enterprise context may be released; the model gateway handles model access, routing, and provider controls.

Is the AWS deployment production ready?+

It is a complete controlled-evaluation stack. Broad production use requires the documented hardening steps, including per-workload clients, reviewed policy, alarms, budgets, retention, networking decisions, and adversarial testing.

How are token savings calculated?+

The included fixture compares deterministic estimates for full context and the released capsule: 32 versus 16 tokens, or 50%. A company pilot should use the model provider's reported input and cached-token usage, actual pricing, and the same task set across all benchmark paths.

How do you keep token reduction from hurting quality?+

Define must-find cases and an acceptance threshold before the pilot. Compare changed-files-only, full-context, and Secure Context Cache capsule runs. Count savings only when the optimized path preserves the agreed recall, precision, and reviewer acceptance.

Can it work with Amazon Bedrock and other models?+

Yes. The repository includes a Bedrock Converse client example, while the capsule format remains model agnostic for internal gateways and other approved model providers.

What should the first use case be?+

Choose one read-only workflow with clear scope and repeatable context, such as IaC security review, architecture Q&A, incident assistance, or developer onboarding.
